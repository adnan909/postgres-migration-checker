Postgres Migration Safety Checker

Paste a migration. See which statements will lock or rewrite a live table, fail on a table that has data, or break the app while it deploys, with a safe rewrite for each one.

Runs entirely in your browser. Your SQL is never uploaded; we only count anonymous page visits (GoatCounter, no cookies). Rules target PostgreSQL 11+ and were verified against PostgreSQL 16.

Check every pull request automatically. The free GitHub Action runs these rules on changed migrations and comments with the safe version.

Why "it worked in dev" isn't enough

Most dangerous migrations run in milliseconds on a development database with ten rows. In production, the same statement can hold an ACCESS EXCLUSIVE lock for minutes, or wait behind one long query while every request piles up behind it. The checker reads your SQL statically, so it catches these before they run against real data.

It doesn't know your table sizes or traffic, so treat a finding as "check this", not "this will definitely cause an outage". Statements on a table created earlier in the same migration are treated as safe, since that table is empty.
